# PairPrototypeGame
A prototype Unity game featuring minimalist platforming with a color twist

Members: John Tu, Yen (Robert) Chiang, Prathiksha Ravibabu Nijamkari

# Overview:
The goal is to jump across moving colored platforms in a one-way forward direction, where green is safe and red is hazardous. There are multiple paths that the player can take, but overall, the goal is to reach the goal indicated by golden yellow platforms.

## Game Controls:
WASD and/or arrow keys to move

Spacebar to jump
